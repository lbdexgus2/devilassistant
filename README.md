# Insightful AI Assistant

Start creating an AI app that is good at searching and answering in-depth questions, deep in terms of problems, code, explaining various things by calculating and responding to people's questions, directly to the question, using API to respond & web format & has a system to store chat. Go back to the old chat conversation and have a new chat start button & UI, 1 chat channel, print box, making it one of the same as the chat channel. It doesn't have to be very big, float a little higher, the chat frame looks comfortable, AI has a display of calculation letters or real thinking. 

There is a button to send photos and files. Text to send photos to full size. Click to see beautiful photos. The system shows the title in the middle of the screen at the top like lovable.



Various settings, which at this point you have to think about what you should do. The name AI (Devil AI) white & black web tone can choose which color to choose.
